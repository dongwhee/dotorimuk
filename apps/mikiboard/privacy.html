Mikiboard 개인정보처리방침

최종 업데이트 및 시행일: 2026-09-01

dotorim(이하 "개발자")은 Mikiboard(이하 "앱")를 운영하면서 이용자의 개인정보를 소중히 다룹니다. 본 방침은 앱이 어떤 정보를 다루고 다루지 않는지 설명합니다.

🔒 Mikiboard는 입력 내용, 키 입력 또는 사용 기록을 수집·저장·추적·전송하지 않습니다.

1. 수집하는 정보

앱과 키보드 익스텐션은 입력 내용, 키 입력 또는 사용 기록을 포함한 개인정보를 수집·저장·추적·전송하지 않습니다. 앱과 키보드 익스텐션은 네트워크 통신을 하지 않으며, 키보드 익스텐션은 클립보드에 접근하지 않습니다.

2. 키보드 "전체 접근" 권한에 대하여

iOS 키보드 설정의 "전체 접근 허용(Full Access)"은 선택 사항입니다. 허용하면 햅틱 피드백을 사용하고, 키보드 익스텐션이 앱에서 선택한 설정을 기기 내부 App Group에서 읽을 수 있습니다. 허용하지 않아도 핵심 입력 기능은 작동하며, 키보드는 자체적으로 사용할 수 있는 설정이나 기본 설정을 사용합니다. 전체 접근 허용 여부와 관계없이 입력 내용은 수집·저장·추적·전송되지 않습니다.

3. 기기에 저장되는 정보

자판 배열, 입력 감도, 햅틱 강도 등 사용자가 앱에서 선택한 설정은 기기 내부 App Group에만 저장되며 외부로 전송되지 않습니다. 전체 접근을 허용하면 키보드 익스텐션이 이 설정을 읽을 수 있습니다.

4. 제3자 제공 및 추적

앱은 광고, 분석 도구, 추적 기술, 제3자 SDK를 일절 사용하지 않습니다. 따라서 이용자 정보가 제3자에게 제공되는 경우는 없습니다.

5. 아동의 개인정보

앱은 어떠한 개인정보도 수집하지 않으므로 아동을 포함한 모든 이용자의 개인정보가 수집되지 않습니다.

6. 방침의 변경

본 방침이 변경될 경우 본 페이지를 통해 변경 내용과 시행일을 공지합니다.
